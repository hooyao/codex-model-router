# Benchmark workspace and checkpoint protocol

This checkout is a pinned Flipt source plus the authentication seed. No external registry or cloud credentials are needed. Use local OCI layouts and loopback HTTP servers in tests. At each round, run the public tests now visible under `.benchmark/public/`; later files are revealed only after a passing checkpoint. Do not inspect evaluator files outside this checkout.

After finishing all worker writes for a round, submit from the checkout root with `python .benchmark/submit_checkpoint.py --round 0 --summary "Initial contract and check status"`. Use `--round 1` and `--round 2` when those reports are revealed. The same helper is present in both arms from round 0. It runs `git diff --check` and the currently visible public Go tests by default, then writes `.benchmark/checkpoint.json` atomically. `--check diff`, `--check public`, and `--check packages` may be repeated to select only those allowlisted checks. Public tests are overlaid from `.benchmark/public/`; no later or hidden tests are available. The overlay check disables Go vet because Windows Go vet cannot open overlay-only test paths; the evaluator's independent public gate runs its own full Go checks. Each check records its actual integer exit code, stdout/stderr SHA-256 hashes, a status record, and arm-local output files. A failing check is recorded as failing; the helper still writes the checkpoint so you can explain it in `--summary` and decide whether to repair before submission. Do not handwrite or edit checkpoint fields.

The helper hashes committed, staged, unstaged, and untracked product changes against the frozen seed tree after checks finish. `.benchmark/` is Git-excluded. `python .benchmark/checkpoint_hash.py` remains available to inspect that hash. The evaluator independently captures the candidate patch, verifies the checkpoint's round, field types, check output hashes, and exact patch hash, then runs the cumulative public gate. One repair submission is allowed per round.

The runner wall limit covers all rounds and descendants: 4,500 seconds per arm, including 25 seconds reserved for cancellation and cleanup. Dispatch stops when observed estimated upper-bound parent and descendant usage reaches $15 per arm. The $18 empirical planning envelope is informational, not a spending target or a guaranteed billed ceiling. Do not run external services. Treat a newly revealed report as additional task requirements. No report prescribes implementation or delegation count.
