## Remaining limitations

Only small-edit has a fixture. All bundled observations are synthetic and no
router savings are claimed. Statistical release pass is deliberately disabled,
including for release-labeled inputs. Bootstrap intervals remain exploratory.
Provider receipt authenticity, complete runtime session observation, append-only
preregistration, live hook compliance, hidden holdouts, and independent task
clusters require a future trusted harness. Hashes do not prevent coordinated
replacement of all inputs or concurrent filesystem mutation during validation.
This worker did not delegate; independent meta-task review belongs to the
controller's separate review assignment.
