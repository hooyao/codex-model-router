## ADDED Requirements

### Requirement: One reproducible fixture task
The suite SHALL contain exactly one fixture-backed task, small-edit, with a
pinned input tree, prompt, reference tree, and grader version. The baseline may
perform direct business work; the router MUST use bounded worker execution.
Synthetic campaigns MUST be deterministic and explicitly labeled.

#### Scenario: Reproduce the fixture
- **WHEN** the campaign generator runs twice from the same fixture
- **THEN** every generated byte and expected result is identical

### Requirement: Exact-tree oracle
The grader MUST accept only the complete reference tree, including byte hashes
and directory inventory. It MUST reject unchanged, unrelated-edit, extra-file,
missing-file, symbolic-link/reparse-point, and hash-mismatch candidates. It MUST
NOT execute candidate code or trust a self-reported passing result.

#### Scenario: A candidate reports success with an unrelated file
- **WHEN** its exact tree differs from the reference
- **THEN** the oracle fails and comparison cannot count it as success
